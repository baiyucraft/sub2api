# 测试与质量

后端：

```bash
cd backend
go test -tags=unit ./...
go test -tags=integration ./...
go test ./...
golangci-lint run ./...
```

前端：

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm run lint:check
pnpm run typecheck
pnpm run test:run
pnpm run build
```

仓库级 `make test` 组合后端测试、前端 lint/typecheck 和关键 Vitest；`make build` 构建前后端。高风险边界包括认证、计费、网关 failover、流式响应、迁移和安全 middleware。
