# 网关与上游

网关经过 API Key 鉴权、用户/组策略、并发与速率限制、账号/渠道调度后转发到 provider。账号、group、channel 保存资源、代理、定价、健康和调度权重；gateway service 处理协议兼容、流式输出、用量、计费和错误映射；adapter/probe 负责 provider-specific auth、模型和健康证据。

流式响应开始输出后不应透明切换账号；错误映射和 failover 资格需同时核对 handler、service、adapter 和 focused tests。
