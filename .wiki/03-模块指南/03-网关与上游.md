# 网关与上游

网关经过 API Key 鉴权、用户/组策略、并发与速率限制、账号/渠道调度后转发到 provider。账号、group、channel 保存资源、代理、定价、健康和调度权重；gateway service 处理协议兼容、流式输出、用量、计费和错误映射；adapter/probe 负责 provider-specific auth、模型和健康证据。

流式响应开始输出后不应透明切换账号；错误映射和 failover 资格需同时核对 handler、service、adapter 和 focused tests。

本 fork 的上游配置、派生账号生命周期、模型能力同步、健康探针、Juice 可信度、TTFT 调度反馈、精确倍率和图片/视频能力判断，统一见[分叉扩展与兼容性](./05-分叉扩展与兼容性.md)。其中：

- 后台探针是否受真实流量抑制，取决于可信度配置是否“显式存在且 `enabled=true`”；
- OpenAI Juice 只统计有效完成响应，网络异常不进入可信度分母；
- 视频支持必须有有效 effective video multiplier，不能只凭能力开关字段判断；
- 上游派生账号编辑继续执行白名单和 OpenAI 专用类型校验。
