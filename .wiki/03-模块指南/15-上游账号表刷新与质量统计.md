# 上游账号表刷新与质量统计

上游账号表的健康、质量和调度保护展示是只读投影。刷新不得发起额外探针、推进恢复计数或改写健康事实。质量评分继续使用 v5，统计窗口、错误去重、缺失 duration 和无评级筛选以既有 Go 判断函数为准。

## 列表 API

`GET /api/v1/admin/upstream-management/accounts` 沿用现有筛选、排序、full/lite 和分页结构；管理账号列表的共享读取也支持可选 `include_quality=1`。返回分页 `data` 内增加可选 `quality_stats`（账号 ID 到统计的映射）及 `quality_stats_status: ok|unavailable`，不请求时不增加这两项。质量列隐藏且没有质量筛选时跳过质量计算。

每次请求固定一个评估时间，响应头 `X-Account-Evaluated-At` 使用 UTC RFC3339Nano；评估时间不写入 ETag 业务体。质量筛选对稳定候选统计一次，筛选/分页和页内展示复用同份结果。筛选统计失败返回 `503 / ACCOUNT_QUALITY_FILTER_UNAVAILABLE`，不得以缺省评级形成分页。普通页内质量读取失败保留账号列表、返回 `unavailable`，前端仅保留同账号、同 Key 的最后成功质量。换 Key 不沿用旧质量。

ETag 在完整生成当前响应后比较，账号数据、质量数据及失败状态均参与；时间窗口自然到期和新事实不能被提前304或固定TTL掩盖。旧批量质量接口继续兼容，并委托相同统计实现。账号质量不保存跨请求的完成结果；精确评估窗口、授权范围及完整查询身份相同的进行中读取可以共享，调用方独立取消，最后一个等待者离开才取消底层读取，查询仍有界超时。

## 健康数据

历史批量读取使用 PostgreSQL LATERAL 每 Key 定位最新24条，排序严格保持 `observed_at DESC, id DESC`，最终展示顺序不变。只对缺少持久历史的有效 Key 读取旧 extra；软删除或不存在 Key 不复活历史。迁移300新增覆盖 `(upstream_key_id, observed_at DESC, id DESC)` 的非唯一索引，不改任何旧迁移。

confidence 先批量确定模式、绑定和身份，再读取 legacy 或 distribution 所需证据。独立 distribution 不受无关 legacy 数据源故障影响；分布身份升级和租约恢复仍以既有CAS核验。legacy 窗口计数精确聚合，最新证据和最新有分数证据分别有界读取，保留 JSON 类型分类、缺失值、24小时/7天边界及原最终判断。损坏事实不静默视为成功，管理读取不推进试用或恢复。

confidence_checks校验按精确序列化JSON文本形状去重后验证，不能按JSONB值相等去重：JSONB把 `1` 与 `1.0` 判为相等，而原Go整数解码器会拒绝 `1.0`。所有计数保留原JSON类型及整数范围语义。窗口内每条confidence_evidence均须保留原Go `map[string]interface{}` 解码的float64语义：非最新记录、未知字段、嵌套对象和数组中的数字溢出也应使该读取失败，不能只验证最终返回的latest；下溢到零或略高于MaxFloat64但可舍入回有限数的输入保持原行为，不能粗略用MaxFloat64比较取代解码语义。该合同的SQL差分结果单独记录，不由文档描述代替验证。PostgreSQL时间精度为微秒，24小时/7天计数边界向上取整到微秒，以等价于Go纳秒固定时钟的年龄比较；最新证据与最新有分数证据仍使用原SQL下界参数，不跟随计数边界改写。没有新增上界过滤，旧读法包含的未来事实继续保留。差分验证在边界两侧加入100/900纳秒偏移、不同数字文本形状与同刻ID；去重形状全部唯一的退化负载另测SQL开销，不能仅凭常见重复形状获益宣称全部场景达标。

页内独立批量读取采用最多4项并发；按账号/Key集合批量访问，不按每个账号启动查询。代理并发读取按整页聚合为一个 Redis batch，保留不同账号的归属及部分失败口径。展示依赖失败不写回健康或调度保护状态。

## 刷新与渲染

质量跟随整表用户选择的5/10/15/30秒周期；本轮一个列表响应同时携带行与质量，手动刷新重新计算。今日统计、远程用量保持各自更新规则，不因质量刷新增加远程探测。

自动、手动、筛选及分页共用请求协调器，身份覆盖页面、筛选、排序、列需求及代次。同上下文自动刷新合并；手动点击遇到更早请求时等待并最多补一轮，重复点击不累积。切换上下文、卸载时取消旧请求；旧响应不得回写新上下文。换页、筛选或其他身份变化时立即清空旧上下文的行与总数，新上下文请求失败也不把旧行用于显示、选择或导出；相同上下文的后台刷新失败则保留最后成功内容。尝试时间和成功时间分开，失败后按所选5/10/15/30秒周期重试，不因失败延长周期或停掉后续刷新；页面交互入口收束请求拒绝，避免未处理的Promise异常。后台、编辑及健康详情显示期间暂停底表，恢复或关闭详情只补一轮。

递归比较完整JSON结构并按账号ID配对，保留响应顺序与未变化路径引用，覆盖新增/删除字段、空值、数组顺序和对象键序。健康组件只接收健康所需字段；已有数据的后台刷新只改变工具栏状态，质量格不反复显示loading。相对成功时间使用共享分钟时钟，暂停/限流等到期状态保留实际时间边界判断。 客户端将服务端 `evaluatedAt` 与本地请求发起时刻 `evaluationRequestedAt` 配对换算到期边界，慢响应不能把暂停/限流期限整体后移；这两项是本轮评估元信息，不加入ETag业务体。桌面虚拟滚动保持原行为；仅上游表移动卡片启用可回退的 `content-visibility` 和记忆高度占位，以减少布局与绘制，不计为DOM数量下降。

重复数值格式化复用 `Intl.NumberFormat` 对象，缓存键覆盖locale和完整options，最多保留64个格式器。每个数值仍逐次格式化，不缓存数值结果；选项或语言变化不得串用格式器，超出容量时淘汰旧对象。日期使用隐式时区的既有行为保持原样，不加入此缓存；不能因时区解析时机改变日期显示。

健康详情事件和趋势各自绑定 Key、范围及打开代次；关闭、换Key、换范围、卸载均取消旧请求。相同身份刷新失败保留最后成功内容，切换身份清空对应内容，已有图表不因后台加载重建。只在打开、切换范围和手动刷新时请求，不增加30天趋势高频轮询。

## 验证与性能证据

回归入口为 handler 的列表内联质量/ETag测试、repository 的健康历史/confidence/质量SQL差分测试、service的共享读取取消测试，以及前端 AccountsView、健康详情、结构共享和分钟时钟测试。真实PostgreSQL测试覆盖同时间戳ID、软删除Key、异常JSON、窗口边界、缺失duration及重复错误；300验证实际索引、幂等和旧SQL读写兼容。缓存5秒/30秒和TTFT15分钟判断作为独立回归，读取优化不改其语义。

可复现负载工具放在 `.agents/skills/sub2api-production-deploy/scripts/perf/upstream-table/`，浏览器工具位于其 `browser/` 子目录，运行及fixture范围见[浏览器工具说明](../../.agents/skills/sub2api-production-deploy/scripts/perf/upstream-table/browser/README.md)。原始报告和trace保存在 `.tmp`。对照冻结 `8afa2ffe47800773f781279e945bf95d6c2e1067`，同机同配置/数据/负载各至少3次；计算对照强制相同质量重算频率，基线实验适配及其哈希必须披露。版本先后按重复轮次交替AB/BA，并保存尝试和完成顺序；fixture、binary、源码清单、测量时间和实际工具身份均须对应。每次运行的列表、整轮刷新及网关原始样本完整存在，与摘要计数一致且值为有限非负数；缺失运行不能靠其他两次的样本数凑成三次。P99至少1000同cell有效样本才可用于验收，不池化异质负载。静态fixture浏览器测试与VM真实后端联调分别报告。

合成网关响应须校验完整传输和固定SSE结束/usage语义，正常HTTP 200不能代替正文完整性；满载响应逐次核验HTTP 429及容量拒绝的类型、代码和message，不把任意快速错误算作正确拒绝。原始响应正文不进入证据。远端压测与采样进程在独占进程组登记归属，清理先通过独立连接核验并有界停止本任务进程，确认无残留后再删除专属数据库、Redis和临时目录；SSH断开不是进程已停止的证据。归属不明或清理证据失败时保留资源并明确报告。工具延迟子报告与保护状态、清理、浏览器及完整矩阵验收分开；单个规模的normal结果不能覆盖未测规模、筛选、分页或退化场景。

本次交付验收以代码正确、判断等价、刷新稳定、最终生产构建和浏览器功能为要求，最终浏览器采用功能smoke与真实2分钟短稳定性检查；保留的30分钟工具属于可选长测，短检查和较早构建结果不得冒称最终30分钟验证。原定主要重负载整轮刷新P95下降25%、其他正常场景及网关P95/P99回退不超过5%，以及浏览器刷新主线程P95≤50ms、交互P95≤200ms、无>100ms刷新长任务、滚动帧P95≤32ms等性能目标尚未完整达成，保留为改善参考，不再阻挡本次交付；不为追逐指标继续长矩阵或额外调优，也不声称全部性能达标。已测结果按其原fixture、binary和构建身份保留，未跑、未达或样本不足明确记录；标准与4倍降速仍分开报告，不通过减少采样、省略判断、延长有效期或降低刷新频率伪造达标。浏览器fixture只证明本地最终构建的功能，不能代替真实API联调；正式签名Gate、旧镜像验证和生产发布不由本地测试结果代替。
