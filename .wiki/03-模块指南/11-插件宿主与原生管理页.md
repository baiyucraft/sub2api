# 插件宿主与原生管理页

插件宿主同时支持旧版 iframe 管理界面和 Manifest v2 原生管理页。原生页是插件管理下的单页面工作区，由宿主读取签名包内的声明式定义并使用受控 Vue 组件渲染；插件代码不能进入宿主 JavaScript 上下文。

## Manifest 与兼容合同

Manifest v1 保持兼容：`ui.entrypoint` 继续通过现有 sandbox iframe 和 Bridge 打开，不要求重新打包。Manifest v2 显式声明 UI 类型：

```json
{
  "schema_version": 2,
  "ui": {
    "type": "native",
    "definition": "ui/admin-ui.json"
  },
  "requires": {
    "admin_ui": 1
  }
}
```

- `ui.type=native`：`definition` 必须指向包内 `ui/` 下的声明式 JSON，并要求宿主 `admin_ui=1`。
- `ui.type=iframe`：使用 `entrypoint` 和既有 `ui_bridge` 能力，安全边界与 v1 相同。
- `ui.type=none`：插件没有管理页面，宿主不显示页面入口。
- v1 未声明 `type` 时只按 iframe 解释；不得把旧入口隐式转换为 native。
- Manifest、定义文件和所有引用资源都必须列入签名文件哈希表。安装阶段完成解析和校验，不能延迟到管理员打开页面时才发现包损坏。

## 页面与路由

原生插件只拥有一个宿主管理路由：

```text
/admin/plugins
└── /admin/plugins/:pluginKey
```

`pluginKey` 是稳定插件身份，不能使用可能随卸载重装变化的数据库 ID 作为公开 URL。插件不注册任意 Vue 路由，也不拥有孙页面；多块功能通过单页内部的 Tabs、折叠区、表格和局部导航表达。全局侧栏仍只有“插件管理”，进入子页面时保持该入口高亮。

深链接先按 key 查询安装记录，再读取规范化后的 Admin UI 定义。插件不存在、已卸载、定义损坏或宿主能力不足时 fail-closed，显示明确错误和返回插件列表入口。插件停用时允许查看和保存草稿；依赖运行时的状态、测试和动作必须显示不可用。

## 声明式安全边界

原生页只允许宿主组件和受控数据绑定：

- 布局：区块、栅格、堆叠、Tabs、折叠区。
- 展示：文本、提示、徽章、统计、键值列表、表格、日志和空状态。
- 输入：文本、数字、开关、单选、多选、搜索和复选框。
- 操作：保存、重置、刷新、确认、插件 Action 和宿主秘密编辑弹窗。
- 数据源：`config`、`resources`、`status` 和页面本地草稿。

绑定使用受控 JSON Pointer 和有限条件运算。定义禁止任意 JavaScript、HTML、远程资源、动态模块、自由表达式和宿主 DOM 访问。图标、动作、配置路径和资源字段必须来自宿主允许列表。秘密正文只在宿主可信弹窗中读写；声明式页面只能看到 configured 状态。

状态轮询限定为 2～60 秒，并在页面隐藏、保存或执行动作期间暂停冲突请求。配置使用本地草稿，离开页面前提示未保存修改；Action 由宿主生成幂等 ID，并沿用管理员权限和 step-up 校验。

## 接口与缓存

原生页使用宿主管理接口，不创建 iframe UI Session：

```text
GET /api/v1/admin/plugins/by-key/:pluginKey
GET /api/v1/admin/plugins/:id/admin-ui
```

`admin-ui` 只返回安装时已校验并规范化的安全页面模型，不返回包内任意文件。定义缓存按插件安装 ID 和 binary SHA 隔离；升级、卸载或 artifact 身份变化时必须失效。配置、资源、状态、动作和秘密继续复用既有插件管理 API。

## 包校验与发布分类

Native 包校验至少覆盖：Manifest v2 类型与能力、定义路径、文件哈希、签名、页面体积、嵌套深度、节点数量、文本长度、唯一 ID、允许图标、绑定范围、动作名和无脚本/远程资源。双架构包必须携带语义相同的 Admin UI 定义及文件身份，不能让不同架构展示不同管理合同。

发布分类固定如下：

```text
Manifest 解析/schema、admin-ui API、按 key 查询、宿主路由、原生渲染器或安全校验变化
  -> 宿主变更
  -> dev-gated 或 build-chain
  -> 完整宿主镜像 VM Gate

生产宿主已支持所需 admin_ui 版本后，仅插件包内定义或插件私有逻辑变化
  -> plugin-package
  -> 签名包静态校验 + VM 插件 Gate
```

不能用插件包发布绕过宿主管理壳升级。宿主发布必须回归 v1 iframe；插件包 Gate 必须按实际 `ui.type` 验证入口，并拒绝当前宿主不支持的 `requires.admin_ui`。

## 回归重点

- v1 iframe 的 UI Session、sandbox、Bridge 和秘密隔离保持不变。
- v2 `native/iframe/none` 安装、入口显示和非法组合拒绝正确。
- `/admin/plugins/:pluginKey` 深链接、侧栏高亮、返回、停用态和错误态正确。
- 声明式渲染不能执行脚本、HTML、远程资源或越权数据绑定。
- 草稿、离开提醒、轮询暂停、Action 幂等和宿主秘密弹窗正确。
- 升级或卸载后缓存失效，旧 URL 不复用旧定义。
- 原生渲染器路由级懒加载，不增加插件列表和其他管理页面的首屏依赖。

Codex STATE 当前仍使用 Manifest v1 iframe；迁移到原生页属于后续独立插件改造，不能由本合同推断已经完成。
