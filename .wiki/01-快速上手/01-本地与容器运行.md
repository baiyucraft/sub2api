# 本地与容器运行

## 本地开发

```bash
cd frontend
pnpm install
pnpm dev
```

另一个终端：

```bash
cd backend
go run ./cmd/server
```

首次启动可进入 setup wizard，也可使用 `go run ./cmd/server -setup`。

## Docker Compose

```bash
docker compose up -d
docker compose logs -f sub2api
docker compose ps
```

镜像、端口和 secrets 以实际 Compose 文件为准。

## 构建

```bash
make build
```

该目标调用 backend/Makefile 和 pnpm frontend build。Windows 无 make 时使用等价 Go/pnpm 命令。
